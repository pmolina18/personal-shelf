# Self-Learning System

## On Session Start
Read `.kiro/learnings.md` in full. Summarize the current entries in 3-5 bullet points. Apply all entries under 'What Has Worked' and 'Patterns and Preferences'. Avoid all patterns listed under 'What Has Failed'. Then proceed with the user's request.

## On Session End
You MUST update `.kiro/learnings.md` before ending this session. Review what you just did and add any new observations using the format: **[Date] — [Task type]** with Observation, Action, and Confidence fields. If nothing new was discovered, add a brief note confirming existing patterns held. Do not add duplicates or vague entries.
